# نشر CifliX على Render من الهاتف

1. افتح Render واختر New ثم Blueprint.
2. اربط مستودع GitHub: `mustafavip98-boop/CifliX-Android`.
3. وافق على إنشاء Web Service من ملف `render.yaml`.
4. انتظر اكتمال النشر، ثم افتح رابط `onrender.com`.
5. اختبر المسار `/api/health` ثم الصفحة الرئيسية.

الواجهة والخادم في خدمة واحدة، لذلك تستخدم الواجهة `/api` من نفس النطاق ولا تحتاج عنوان localhost أو إعداد CORS منفصل.

ملاحظة: الخطة المجانية قد تدخل الخدمة في وضع السكون بعد فترة من عدم الاستخدام، وقد يتأخر أول طلب بعد ذلك. استخدم فقط المحتوى وروابط البث التي تملك تصريحاً بنشرها، ولا تتجاوز DRM أو ضوابط الوصول.
