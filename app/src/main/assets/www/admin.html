ربط مصدر JSON خارجي

يمكنك إدخال رابط JSON مباشر لكتالوج تملك حق استخدامه. يجب أن يسمح المصدر بطلبات المتصفح (CORS) وأن يحتوي قائمة عناوين. لا يمكن استيراد ملف إضافة CloudStream بصيغة CS3 ككتالوج أفلام.

الاستيراد من رابط خارجي يستبدل المكتبة المحلية بعد تأكيدك.

عن تشغيل الفيديو

حقل رابط المشاهدة يقبل رابط HLS أو MP4 تملك حق بثه. التشغيل يحتاج أن يكون الرابط متاحاً للمتصفح، وقد يحتاج HLS إلى دعم المتصفح أو مشغل متوافق. لا تُدخل روابط خاصة أو مفاتيح سرية في واجهة عامة.
